CSS Grid Animation

Five animated grid interactions, recreated with pure CSS and JavaScript.

01

Ripple Effect

Grid cells pulse outward in sequence

.ripple div {
  animation: ripple 1.5s infinite;
}

@keyframes ripple {
  0%, 100% {
    transform: scale(1);
    opacity: 0.6;
  }
  50% {
    transform: scale(1.5);
    opacity: 1;
  }
}
02

Snake Motion

A moving wave travels across the grid

.snake div {
  animation: snake 1s infinite;
}

@keyframes snake {
  50% {
    transform: translateX(15px);
  }
}
03

3D Flip

Each tile rotates in three dimensions

.flip div {
  animation: flip 1.2s infinite;
}

@keyframes flip {
  50% {
    transform: rotateY(180deg);
  }
}
04

Bounce Grid

Tiles bounce vertically with staggered timing

.bounce div {
  animation: bounce 0.8s infinite;
}

@keyframes bounce {
  50% {
    transform: translateY(-25px);
  }
}
05

Mouse 3D Tilt

Move your pointer over the tiles

.tilt {
  perspective: 500px;
}

.tilt div {
  transition: transform 0.2s;
}
